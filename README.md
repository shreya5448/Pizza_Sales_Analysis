 🍕 Pizza Sales Analysis | Python

 📌 Project Overview
Pizza Sales Analysis is an Exploratory Data Analysis (EDA) project developed using Python. The objective is to analyze pizza sales data, understand customer ordering behavior, identify revenue trends, and evaluate the performance of different pizza categories, sizes, and individual products.

 🎯 Project Objectives
 -Analyze overall sales and business performance.
 -Calculate important business KPIs.
- Identify daily, hourly, and monthly order trends.
- Analyze revenue contribution by pizza category and size.
- Identify the most and least performing pizzas.
- Generate meaningful business insights through data visualization.

 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Key Performance Indicators (KPIs)

| KPI | Result |
| Total Revenue | $817,860.05 |
| Total Orders | 21,350 |
| Total Pizza Line Items | 49,574 |

🔍 Exploratory Data Analysis & Insights

1. Data Understanding & Cleaning
- Imported and explored the pizza sales dataset.
- Checked dataset structure, data types, and missing values.
- Removed unnecessary columns.
- Cleaned and converted order IDs.
- Converted date and time columns into appropriate formats.

 2. Daily Sales Analysis
- Analyzed total orders for each day of the week.
- Calculated total revenue generated on each day.
- Compared daily order volume and revenue trends.

 3. Hourly Sales Analysis
- Analyzed the number of orders placed during different hours.
- Identified customer ordering patterns throughout the day.

 4. Monthly Sales Analysis
- Analyzed total orders across all 12 months.
- Visualized monthly order trends to understand sales patterns.

 5. Sales Analysis by Pizza Category
- Calculated revenue generated by each pizza category.
- Analyzed the percentage contribution of each category to total sales.
- Compared the number of pizzas sold across categories.

 6. Sales Analysis by Pizza Size
- Analyzed sales contribution by different pizza sizes.
- Compared pizza category and size combinations using a heatmap.

 7. Top 5 Best-Selling Pizzas
- Identified the top 5 pizzas based on total orders.
- Identified the top 5 pizzas based on total revenue.

 8. Bottom 5 Performing Pizzas
- Identified the bottom 5 pizzas based on total revenue.
- Compared product performance to understand low-revenue items.
